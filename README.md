# VPN

Клиент и сервер на Xray-core / VLESS / XHTTP. Проект в разработке; готовых проверенных установщиков пока нет.

## Требования

- Клиенты: macOS, Windows, Android.
- Список разрешений пуст по умолчанию. Неодобренные адреса идут напрямую и попадают в очередь.
- Одобрение домена включает его поддомены; IP разрешаются отдельно.
- Одобренные адреса идут только через VPN. Ошибка туннеля никогда не переключает их на прямое соединение.
- Разрешения общие для устройств аккаунта. Регистрацию аккаунта одобряет администратор.
- Уведомления о сбоях и предложения одобрения без повторного спама.
- Сервер самостоятельно проверяет доступные аккаунту направления.
- Деплой через Ansible; секрет администратора задаётся в конфигурации вне Git.
- Актуальные APK, DMG, MSI и контрольные суммы: `installers/current/`.
