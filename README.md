# Линия VPN

Личный VPN с разрешениями для отдельных доменов и IP. Клиенты для **Android, Windows и macOS**, сервер на **Xray-core / VLESS / XHTTP / REALITY**, общая политика устройств аккаунта и административное одобрение регистраций. Собственный домен не требуется.

**Состояние: 0.2.0 preview.** Проверенные результаты и ещё не пройденные платформенные испытания перечислены в [статусе реализации](docs/status.md). Успешная компиляция не равна проверке отсутствия утечек на устройстве.

Неодобренные адреса идут напрямую и попадают в очередь. Одобренные адреса идут только через VPN; при ошибке туннеля прямого переключения нет. Одобрение домена распространяется на его поддомены. Пользователь сам принимает решение о разрешении.
