# Линия VPN

Личный VPN с разрешениями для отдельных доменов и IP. Клиенты для **Android, Windows и macOS**, сервер на **Xray-core / VLESS / XHTTP / REALITY**, вход по личным ключам, общая политика устройств аккаунта и административное одобрение регистраций. Собственный домен не требуется.

**Состояние: 0.2.0 preview.** Проверенные результаты и ещё не пройденные платформенные испытания перечислены в [статусе реализации](docs/status.md). Успешная компиляция не равна проверке отсутствия утечек на устройстве.

При включённом VPN неодобренные адреса идут напрямую; в очередь попадают только адреса с повторными прямыми сбоями. Одобренные адреса и доверенные приложения используют только VPN: при ошибке соединения прямой резерв запрещён. Временная ошибка синхронизации не прерывает работающие VPN-соединения. Одобрение домена распространяется на его поддомены. Пользователь сам принимает решение о разрешении.

Отключение, удаление и очистка старых сетевых настроек: [восстановление сети](docs/network-recovery.md).
