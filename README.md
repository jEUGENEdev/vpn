# Линия VPN

Личный VPN с разрешениями для отдельных доменов и IP. Клиенты для **Android, Windows и macOS**, сервер на **Xray-core / VLESS / XHTTP / REALITY**, вход по личным ключам, общая политика устройств аккаунта и административное одобрение регистраций. Собственный домен не требуется.

**Установщики 0.2.1 опубликованы в Releases: [Android APK](installers/android-preview-20261119/) и [Windows/macOS](installers/desktop-preview-20261118/). Android подписан новым постоянным ключом: переход со старой 0.2.0 требует переустановки после сохранения профиля и ключа входа.** Порядок обновления и ограничения описаны в [проверке установщиков](docs/installer-upgrade.md). Проверенные результаты и ещё не пройденные платформенные испытания перечислены в [статусе реализации](docs/status.md). Успешная компиляция не равна проверке отсутствия утечек на устройстве.

При включённом VPN неодобренные адреса идут напрямую; в очередь попадают только адреса с повторными прямыми сбоями. Одобренные адреса и доверенные приложения используют только VPN; при сбое они блокируются до восстановления. Временная ошибка API не прерывает работающие соединения. Кнопка «Выключить VPN» переводит весь трафик напрямую. [Политика при сбоях и границы защиты](docs/fail-closed-vpn.md). Одобрение домена распространяется на его поддомены. Пользователь сам принимает решение о разрешении.

Отключение, удаление и очистка старых сетевых настроек: [восстановление сети](docs/network-recovery.md).
