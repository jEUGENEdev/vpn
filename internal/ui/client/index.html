Пропустить через VPN?

Здесь только адреса, которые несколько раз не ответили напрямую. Поддомены собраны в группы; разрешить можно весь домен или отдельный адрес.

Только доверенные адреса.

Эти соединения никогда не переключаются на обычную сеть при сбое VPN.

При удалении разрешения адрес снова сможет подключаться напрямую.

Кто выходит в сеть.

По умолчанию VPN включается только для разрешённых адресов. Доверив приложению весь трафик, вы меняете маршрут только для него на этом устройстве.

Служба сейчас не может определять приложения. Правила адресов продолжают работать.

Источник определяется по сетевому соединению в системе. Если установить его нельзя, мы не угадываем приложение по домену или IP.
