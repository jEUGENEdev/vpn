# Актуальные установщики

Сюда workflow `Test and build current installers` помещает комплект APK, MSI и DMG (Intel и Apple Silicon) **только после успешной сборки всех платформ**. Версия, исходный коммит, тип подписи и SHA-256 записываются в `manifest.json` и `SHA256SUMS`.

Бинарные файлы хранятся через Git LFS (`git lfs pull`). До первого успешного запуска CI здесь нет установщиков. Файлы-заглушки не используются.

Версия 0.2.0 — preview: Android подписан ключом разработки, DMG не нотарифицирован Apple, MSI не имеет Authenticode-подписи. Перед обычным использованием обязательны проверки из `docs/acceptance.md`. Обновление Android поверх предыдущей preview-сборки может потребовать повторной установки из-за смены ключа подписи CI.
