## Порядок установки

Перед удалением сохраните профиль сервера и личный ключ доступа. Полное удаление очищает локальные данные и вход; подтверждённые правила аккаунта остаются на сервере. После новой установки добавьте профиль и войдите заново.

- **Windows:** удалите старое приложение через «Параметры → Приложения», при необходимости перезагрузите компьютер, затем запустите новый MSI. Установка поверх и Repair отключены.
- **macOS:** откройте новый DMG → «Установщик Сеть.app» → «Удалить». Затем повторно откройте тот же установщик и выберите «Установить». Один DMG подходит для Intel и Apple Silicon; удаление использует агент из нового DMG.
- **Android:** для чистой установки удалите приложение, установите APK и заново разрешите VPN. Сохранён постоянный сертификат, поэтому также поддерживается обновление поверх APK 0.2.1 и новее, подписанных этим же ключом. VersionCode: `4000`. Для старого APK 0.2.0 с другой подписью нужен [переход с удалением](../../docs/android-signing.md).

Подробности: [установка и удаление](../../docs/installer-upgrade.md) · [macOS](../../docs/macos-installation.md) · [подпись Android](../../docs/android-signing.md).

## Проверки

[Итоговая сборка](https://github.com/jEUGENEdev/vpn/actions/runs/45442737468): Go race/vet, безопасность, переносимые тесты, desktop/DOM и Chromium; нативные установка/удаление, служба, DNS и сетевая защита на Windows и macOS обеих архитектур. Android прошёл четыре сценария со 128 переключениями режимов VPN, повторную установку с сохранением данных и полное удаление с чистой установкой. Подпись, идентификатор и версия готового APK проверены перед публикацией.

[Развёртывание серверных изменений](https://github.com/jEUGENEdev/vpn/actions/runs/45442070939) завершено: Ansible без ошибок, HTTPS API и REALITY на порту 443 проверены, публичные административные маршруты закрыты.

**Preview:** macOS подписан ad-hoc, без нотарификации Apple; Windows без Authenticode. Нативные проверки CI не заменяют приёмку на пользовательских устройствах и сетях. Android использует прежний постоянный ключ; новый ключ не создавался.
