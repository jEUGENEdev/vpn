## Изменения

Сохранение соединений при добавлении устройств и расширении правил; сохранение неизменившихся потоков при синхронизации профиля; отдельный учёт UDP-назначений; прямой резерв отдельно по адресу, приложению, протоколу и порту. Односторонний UDP и обычный простой не включают резерв. Повторные безответные UDP-отправки в одном прямом потоке могут предложить разрешение VPN; поздний ответ снимает предложение.

Комплект включает прежние исправления восстановления сети (#14) и серверной ошибки переполненной очереди «Оставить напрямую» (#15). Отзыв/сужение доступа по-прежнему может перезапускать серверный транспорт и кратковременно прерывать другие устройства.

## Комплект и инструменты

APK, MSI, DMG для Apple Silicon и Intel, Linux amd64 сервер и генератор профиля. Go 1.27.4, Electron 45.3.3/electron-builder 26.18.0, JDK 21, Android build-tools 35, NDK 28.0.13004108, Gradle 8.11.1. Android собран с offline-кэшем, desktop использует зависимости того же package-lock.json. Сборки используют `-tags with_gvisor`, кроме keygen; исполняемые файлы — `-trimpath`, snapshot — `GOFLAGS=-buildvcs=false`.

Упаковка Windows выполнена через штатный package.py и адаптер WiX 4 → WiX 3/wixl. ProductCode `B147118A-2AE3-59D6-8A2B-594402D4525E`.

## Применение и ограничения

Обновить нужно сервер и клиенты. Повторно генерировать профиль сервера не требуется: существующие ключи, сертификаты и база совместимы. Для штатного обновления скачайте текущий репозиторий и повторите `bash deploy.sh` / `deploy.bat` с прежними четырьмя значениями. Сценарий описан в docs/deployment.md. Linux-бинарники — не установщик и не замена конфигурации Ansible.

Автодеплой этого коммита [остановлен GitHub Actions](https://github.com/jEUGENEdev/vpn/actions/runs/44067713291) до запуска: ошибка оплаты аккаунта или лимита расходов. Деплой на VPS не выполнялся. SSH-подключение к VPS в данном окружении не настроено.

Нативная установка/обновление и работа VPN на физических Android/Windows/macOS, реальном пользовательском VPS и packet capture не проверялись. Локальные сетевые тесты не заменяют эту приёмку. Android — debug-подпись; Windows — без Authenticode; macOS — ad-hoc без Apple-нотарификации, PKG не подписан. Версии приложения остаются 0.2.0 preview (Android versionCode 2); комплекты различаются по SHA и тегу.

manifest.json содержит размеры и SHA-256 бинарников. SHA256SUMS включает остальные 9 assets. Архив рецепта содержит команды, адаптеры, отчёты и source-proof без SDK и секретов. Временные метки контейнеров не гарантируют побитовую воспроизводимость.
