# Сеть 0.3.3: установка фоновой службы и название Windows

Исходники слиты в main через [PR #43](https://github.com/jEUGENEdev/vpn/pull/43), коммит `9be48a1257ef4337fc3fad1a774715a9e3a32771`. Все три установщика собраны после слияния из этого дерева. Готовые установщики переданы владельцу. Публикация файлов в GitHub Releases не завершена: две попытки прикрепления файлов зависли; релиз 0.3.3 не опубликован.

## Найденные причины и изменения

- Опубликованный MSI 0.3.2 содержал ServiceInstall.ErrorControl=1: ошибка регистрации службы не была обязательной ошибкой установки. Теперь задан Vital, в готовом MSI проверено значение 32769. Linux wixl игнорирует Vital даже при явном указании, поэтому адаптер кросс-сборки восстанавливает флаг в таблице; нативная сборка WiX также проверяет его.
- Установка Windows проверяет доступность локального HTTPS API службы после StartServices и до завершения транзакции. Неудачная регистрация или неготовая служба теперь завершают установку ошибкой, а не оставляют успешную установку с неработающим интерфейсом. Проверка только читает состояние, не выключает VPN и не меняет профиль.
- В Windows запускается `Сеть.exe` с названием, версией 0.3.3 и иконкой «Сеть». Ярлык меню «Пуск» указывает на этот файл. Обновление принудительно заменяет устаревшие файлы Electron, включая файл со старым более высоким номером версии. Отказ пользователя от автозапуска сохраняется при миграции старого пути.
- Интерфейс загружается сразу и допускает задержку запуска службы. Временная недоступность больше не объявляется отсутствием службы. Убрано требование выбрать несуществующий пункт восстановления: повторный запуск того же MSI выполняет восстановление автоматически. Устаревший токен не требует перезапуска интерфейса.
- В macOS postinstall проверяет фактическую готовность службы после launchctl. Единый DMG содержит один «Установщик Сеть.app» с установкой/обновлением и удалением для Intel и Apple Silicon.
- Android пересобран как 0.3.3 / versionCode 3003 прежним постоянным ключом. Проверена совместимость обновления с опубликованным APK 0.3.2 и 16 KiB выравнивание ZIP/ELF.

Идентификаторы MSI UpgradeCode, службы, macOS bundle, Android package и ключ Android сохранены. Upgrade/repair сохраняют профиль и правила и не запускают восстановление сети. Изменения сервера и обновление VPS для этого исправления не нужны.

Readiness-тесты проверяют настоящий TLS-канал службы, отказ на чужом сертификате до передачи токена, 401, перенаправление, неверное состояние, отсутствующие файлы и остановку службы. Нативный сценарий Windows дополнен запуском настоящего GUI и ремонтом удалённой регистрации службы; скрывающий сбой ручной Start-Service удалён из теста.

## Ограничения доказательств

Сборка выполнена кросс-компиляцией в Linux. Реальные установка/обновление/удаление, Windows SCM/WFP, macOS launchd/PF/Gatekeeper и VPN на устройствах не проверены. GitHub Actions run 45236084419 завершился до выполнения шагов, нативные задания пропущены. Это preview, а не подтверждённая нативная приёмка.

Полный portable check остановился на Ansible fixture (`Local RPC server did not start`); отдельный SSH fixture получил `Connection reset by peer`. Chromium UI check не запустился из-за отсутствующего browser executable. Эти проверки не считаются пройденными. Проверка Apple PlistBuddy пропущена на Linux.

Windows MSI/EXE не имеют Authenticode-подписи. Приложения и агент macOS имеют ad-hoc подпись, без нотарификации Apple; PKG не подписан. Android использует закреплённый сертификат SHA-256 `a5ed967ba9dd5cc7626793c6b8eae8ab7d8a904e855355b71d6ba9b17e84b8a5`.

## Установка и диагностика

Windows: запустить новый MSI поверх установленного приложения. Повторный запуск этого же MSI восстанавливает компоненты автоматически. Не требуется выбирать пункт «Восстановление». Если установка завершится ошибкой, выполнить `msiexec /i Set-0.3.3-windows-x64.msi /L*V set-install.log` из каталога скачанного файла и приложить журнал; перед публикацией проверить его на личные данные.

macOS: открыть DMG и «Установщик Сеть.app», выбрать установку/обновление. Android: установить новый APK поверх 0.3.2/0.3.1/0.3.0 либо 0.2.1 от 19.11.2026 с тем же сертификатом. Для старой 0.2.0 действует docs/android-signing.md.

SHA256SUMS содержит контрольные суммы всех вложений, кроме самого SHA256SUMS. Архив Set-0.3.3-build-evidence.zip содержит рецепты кросс-сборки, результаты извлечения и журналы проверок; ключей подписи и рабочих профилей в нём нет.
