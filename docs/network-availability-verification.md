Go-регрессии проверяют прямой маршрут при ошибке открытия VPN, отсутствие повторной отправки данных зависшего потока, fallback после ошибки записи без чтения, отмену запроса, сохранение работающего прямого соединения при неудачной синхронизации, сохранённый off и повторную попытку включения. Проверены DHCP/custom DNS, неполный/повреждённый бэкап, продолжение восстановления после ошибки одного интерфейса и сохранение пользовательских DNS. Mobile-проверки покрывают закрытие TUN, повторную остановку, ошибку открытия TUN с доступным UI и ограничение Android lockdown.

Нативные скрипты дополнены реальными off/on, системным DNS после включения, stop, аварийным завершением и uninstall. Windows отдельно проверяет старые WFP-объекты и автономный PowerShell recovery; macOS — отсутствие временной DNS-записи после остановки. Это подготовленные сценарии, а не заявление о пройденной проверке ОС.

Файлы `installers/current` не заменены и нового поведения не содержат. Локальная сборка APK и кросс-сборки агентов не являются выпуском комплекта установщиков. Перед выпуском нужны нативные прогоны из [acceptance.md](acceptance.md).
