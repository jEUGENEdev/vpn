# Статус 0.2.0 preview

Android 0.2.1 от 19.11.2026 собран и проверен статически; используется новый постоянный ключ. APK ещё не опубликован в Releases. [Сборка, миграция и ограничения](../installers/android-preview-20261119/). Нативные Android-проверки, описанные ниже, относятся к более ранним сборкам.

**Исправление частичных сбоев (исходники):** устранены обрыв медленных TCP-потоков через 20 секунд, отключение рабочих VPN-потоков при временной ошибке API и ложные сообщения о восстановлении от другого адреса. Защищённый трафик не переключается напрямую после ошибки. [Причины, проверки и границы изменения](partial-vpn-stability-2026-11-17.md). Для применения нужны новые клиенты; опубликованный ниже комплект эти изменения ещё не содержит.

**Исходники после объединения PR #16/#17/#18:** сохранение сессий при синхронизации и добавлении устройств/правил, обработка всех UDP-назначений, независимый резерв по адресу/приложению/протоколу/порту и корректная диагностика медиапотоков. [Проверки и ограничения](pr-16-17-integration.md). Установленный на VPS код этим статусом не подтверждается.

**Текущий комплект:** [четыре установщика и Linux-бинарники](../installers/current/README.md) из `d067d97`, [релиз v0.2.0-preview.20261117.4](https://github.com/jEUGENEdev/vpn/releases/tag/v0.2.0-preview.20261117.4). [Проверки упаковки](manual-build-media-integration-2026-11-17.md). Нативная приёмка и обновление VPS остаются открытыми; автодеплой остановлен GitHub Actions до запуска из-за оплаты/лимита.

Конфликты общих файлов разрешены с сохранением функций всех четырёх PR. Отчёт с проверенными SHA, исправлениями совместимости и ограничениями: [pr-integration-review.md](pr-integration-review.md).

## Вход по ключам и управление VPN

Добавлены перевыпуск общего профиля с отзывом старой ссылки и опциональным отзывом устройств; пользовательский вход по случайному ключу с сохранением имени; замена/восстановление ключа в админке и клиенте; кнопка включения/выключения VPN с подтверждением прямого режима и сохранением выбора. Пароли пользователей больше не принимаются; миграция описана в `client.md` и `deployment.md`.

Для изменений локально прошли `go test -race -tags with_gvisor ./...`, `go vet -tags with_gvisor ./...`, сборка Linux-сервера, проверки синтаксиса JavaScript и тесты deployment-скриптов. В окружении не удалось запустить Chromium (создание системного сокета запрещено); облачный браузер недоступен для локального fixture-сервера. Поэтому новые Playwright-сценарии пока не считаются пройденными. Проверка на реальном VPS и нативных клиентах также остаётся открытой.

Источник текущих установщиков указан в `installers/current/manifest.json`. Ниже сохранены результаты прежних версий; они не подтверждают нативную приёмку последнего комплекта.

## Предыдущая версия

В 0.2 добавлены стабильные списки и группы доменов, предложения только после повторных прямых сбоев, определение приложения и локальное доверие его трафику. Нативные сценарии расширены проверками владельца реального соединения и блокировки доверенного приложения без VPN.

Реализованы исходники клиента, сервера, аккаунтов, admin approval, UI, TUN-маршрутизации, общего allowlist, уведомлений, Ansible и платформенной упаковки.

Локально пройдены unit/integration-тесты политики, регистрации/одобрения/блокировки аккаунтов, привязки и отзыва устройств, границ доступа разных аккаунтов, наследования доменов, прямого маршрута для неразрешённых IP, запрета прямого fallback, DNS после перезапуска, антиспама уведомлений. Пройден запуск тестов с Go race detector. Проверен настоящий TCP/UDP round trip через Xray/VLESS/XHTTP/REALITY и серверный отказ после удаления разрешения. Go-служба скомпилирована для Windows x64 и macOS arm64. Проверены выпуск и обновление сертификата с сохранением pin, IPv4/IPv6-конфигурация и синтаксис Ansible. В CI прошли тесты UI и сборки DMG; полный комплект подтверждается manifest установщиков.

На macOS 15 Intel и macOS 26 Apple Silicon CI проверены установка PKG, запуск службы, Fake-DNS, direct, блокировка локально одобренного IP без сервера и сохранение PF после остановки службы.

На Windows CI проверены установка MSI, запуск службы/Wintun, Fake-DNS, прямой запрос, блокировка одобренного IP без сервера и сохранение WFP после остановки службы. На Android 15 x86_64 в эмуляторе пройден instrumentation-тест: установка APK, VpnService/TUN, Fake-DNS, direct и блокировка локально одобренного IP без сервера.

Не проверены на устройствах пользователя: полный цикл с реальным VPS, защита после принудительного падения/загрузки, нативные уведомления, обновление, смена сетей и обходы через DNS/ECH. Полная таблица — `acceptance.md`. Пока эти проверки не пройдены, продукт нельзя считать VPN с доказанной защитой от утечек.

Состояние установщиков определяется фактическими файлами и `manifest.json` в `installers/current/`, а состояние CI — GitHub Actions. Пустая папка означает, что первый комплект ещё не собран; файлы с расширениями APK/DMG/MSI не подменяются заглушками. Подписанный production-релиз требует отдельных ключей Android/Windows и Apple Developer ID/notarization.

## Изменения устройств и macOS (17 ноября 2026)

В исходниках добавлены автоматическое системное имя и выбор/добавление при недоступном имени, повторная авторизация без дубликата, полное удаление устройства с очисткой ключей и кодов, скрытие пользовательских разрешений из admin API/UI. Исправлено завершение активных XHTTP-потоков при замене конфигурации: Runtime теперь отменяет контекст экземпляра Xray, а не только закрывает слушатели.

Локально для этих изменений пройдены `go test -race -tags with_gvisor ./...`, `go vet -tags with_gvisor ./...`, проверки реальных TCP/UDP-потоков и старых ключей после удаления, DOM-сценарии изменённого UI, синтаксис JS/Bash/YAML/plist и схема electron-builder 26.18.0. Go-агент скомпилирован для macOS arm64/amd64 и Windows amd64. Chromium/Playwright в текущей Linux-среде не запустился из-за запрета системного socket; визуальные проверки остаются в CI. DOM-проверка не заменяет визуальный тест.

Упаковка macOS теперь явно подписывает preview ad-hoc, проверяет финальный DMG/PKG и архитектуру; нативный CI запускает GUI из образа. Добавлен отдельный режим подписанного/нотарифицированного release. Эта редакция скриптов ещё требует нативного прогона на Intel/Apple Silicon и проверки скачанного установщика с quarantine. Она не обновляет старые DMG автоматически: наличие новой сборки подтверждается только `source_commit` в `installers/current/manifest.json` и результатами CI.
