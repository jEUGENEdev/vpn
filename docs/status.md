# Статус 0.1.0 preview

Реализованы исходники клиента, сервера, аккаунтов, admin approval, UI, TUN-маршрутизации, общего allowlist, уведомлений, Ansible и платформенной упаковки.

Локально пройдены unit/integration-тесты политики, регистрации/одобрения/блокировки аккаунтов, привязки и отзыва устройств, границ доступа разных аккаунтов, наследования доменов, прямого маршрута для неразрешённых IP, запрета прямого fallback, DNS после перезапуска, антиспама уведомлений. Пройден запуск тестов с Go race detector. Проверен настоящий TCP round trip через Xray/VLESS/XHTTP/REALITY и серверный отказ после удаления разрешения. Go-служба скомпилирована для Windows x64 и macOS arm64.

Не проверены на реальных устройствах: системный TUN, persistent firewall после падения/загрузки, нативные уведомления, установка/обновление и обходы через DNS/ECH. Полная таблица — `acceptance.md`. Пока эти проверки не пройдены, продукт нельзя считать VPN с доказанной защитой от утечек.

Состояние установщиков определяется фактическими файлами и `manifest.json` в `installers/current/`, а состояние CI — GitHub Actions. Пустая папка означает, что первый комплект ещё не собран; файлы с расширениями APK/DMG/MSI не подменяются заглушками. Подписанный production-релиз требует отдельных ключей Android/Windows и Apple Developer ID/notarization.
