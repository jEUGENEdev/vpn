# Статус 0.1.0 preview

Реализованы исходники клиента, сервера, аккаунтов, admin approval, UI, TUN-маршрутизации, общего allowlist, уведомлений, Ansible и платформенной упаковки.

Локально пройдены unit/integration-тесты политики, регистрации/одобрения/блокировки аккаунтов, привязки и отзыва устройств, границ доступа разных аккаунтов, наследования доменов, прямого маршрута для неразрешённых IP, запрета прямого fallback, DNS после перезапуска, антиспама уведомлений. Пройден запуск тестов с Go race detector. Проверен настоящий TCP/UDP round trip через Xray/VLESS/XHTTP/REALITY и серверный отказ после удаления разрешения. Go-служба скомпилирована для Windows x64 и macOS arm64. Проверены выпуск и обновление сертификата с сохранением pin, IPv4/IPv6-конфигурация и синтаксис Ansible. В CI прошли тесты UI и сборки DMG; полный комплект подтверждается manifest установщиков.

На Windows CI проверены установка MSI, запуск службы/Wintun, Fake-DNS, прямой запрос, блокировка одобренного IP без сервера и сохранение WFP после остановки службы. На Android 15 x86_64 в эмуляторе пройден instrumentation-тест: установка APK, VpnService/TUN, Fake-DNS, direct и блокировка локально одобренного IP без сервера.

Не проверены на устройствах пользователя: полный цикл с реальным VPS, защита после принудительного падения/загрузки, нативные уведомления, обновление, смена сетей и обходы через DNS/ECH. Нативная установка macOS пока требует исправления. Полная таблица — `acceptance.md`. Пока эти проверки не пройдены, продукт нельзя считать VPN с доказанной защитой от утечек.

Состояние установщиков определяется фактическими файлами и `manifest.json` в `installers/current/`, а состояние CI — GitHub Actions. Пустая папка означает, что первый комплект ещё не собран; файлы с расширениями APK/DMG/MSI не подменяются заглушками. Подписанный production-релиз требует отдельных ключей Android/Windows и Apple Developer ID/notarization.
