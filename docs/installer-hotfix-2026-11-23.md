# Исправление установщиков desktop 0.3.2

База изменения: `main` / `aa8ce27ee56f5340295e504b0460fc24ed0856ad`.
Изменены установщики и проверки упаковки; сервер и сетевой runtime не менялись.
Обновление сервера для этого исправления не требуется.

## macOS: ошибка до замены файлов

Журнал пользователя указывает на `preinstall: Cannot compare installed Сеть version`.
Скрипт читал `CFBundleShortVersionString` одновременно из `LineVPN.app` и
`Сеть.app`, даже если соответствующего приложения не было. `PlistBuddy` может
вывести `File Doesn't Exist, Will Create: …` в stdout; перенаправление stderr и
`|| true` сохраняли этот текст в переменной версии. Поэтому чистая установка,
повторная установка после удаления и обновление с единственным именем приложения
могли завершаться одинаково. Остановка службы в этом сценарии ещё не выполнялась.

Теперь отсутствующее приложение не опрашивается. Для существующего приложения
обязательны файл метаданных, успешное чтение и непустая версия. Повреждённые
метаданные, чужой bundle ID и понижение версии по-прежнему блокируют установку
до остановки процессов. Защита сети и данные пользователя не очищаются.

Регрессионный fixture теперь воспроизводит stdout и код возврата PlistBuddy.
До исправления чистая установка и обновление с одним именем падали с той же
строкой, что в журнале; после исправления проходят. Добавлен безопасный тест
с настоящим PlistBuddy на Mac и временными plist; службы в нём остаются заглушками.

## Windows: устаревший EXE и ярлык

В опубликованном MSI 0.3.1 у всех файлов отсутствовал `File.Version`, включая
версионированный `LineVPN.exe`. Ручной Linux-адаптер wixl не переносил PE-версии.
Кроме того, `REINSTALLMODE=amus` назначался только при `Installed`, то есть при
repair того же ProductCode, но не при major upgrade. Это допускало сохранение
старого EXE Electron рядом с новым `app.asar`. Точное состояние Windows пользователя
без журнала MSI не установлено; подтверждены дефекты опубликованного пакета.

- Режим замены файлов и обновления значков применяется также к установке новой
  версии. `REINSTALL=ALL` остаётся только для repair. Понижение версии продукта
  по-прежнему блокируется, прежний продукт удаляется внутри транзакции.
- Новый ярлык `Сеть.lnk` создаётся непосредственно в общем меню «Пуск» с собственным
  GUID и отдельным registry key path. Он не переиспользует компонент старой папки
  `LineVPN` / `Сеть`; старые зарегистрированные ресурсы удаляет прежний MSI.
  Пользовательские закрепления и ярлыки других приложений не удаляются.
- Сборка проверяет реальные PE ProductName/FileDescription, версии и все размеры
  иконки. Отдельная проверка готового MSI сверяет каждую File.Version с payload.
- В новой ручной сборке заполнены версии и языки пяти версионированных PE-файлов;
  значения считаны из бинарников, затем проверены повторным чтением MSI.
- Нативный upgrade-тест моделирует установленный EXE с именем Electron и версией
  45.3.3, затем проверяет фактические байты нового EXE/ASAR/агента и ярлык.

Правила Windows Installer: [REINSTALLMODE](https://learn.microsoft.com/en-us/windows/win32/msi/reinstallmode),
[замена файлов](https://learn.microsoft.com/en-us/windows/win32/msi/replacing-existing-files),
[идентичность компонентов](https://learn.microsoft.com/en-us/windows/win32/msi/changing-the-component-code).
