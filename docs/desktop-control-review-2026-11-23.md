# Локальное управление и название «Сеть» — 23 ноября 2026

Правка поверх PR #39, commit `0111bc4a4768d98b6ec9631a57c849e4a7f18c03`.
Это ревью автора и локальные проверки, без независимого аудита и развёртывания.

## Воспроизведённый обход

Desktop сохранял `ui-token`, доступный обычным пользователям машины, и принимал
с ним все команды локального API. Регрессионный тест на исходном обработчике
получил HTTP 200 и включил режим `all`: локальное приложение могло выдать себе
разрешение без согласия. На исправленном обработчике тот же запрос получает 403,
режим остаётся прежним. Ограничение прав файла до пользователя GUI само по себе
не отделило бы другие процессы того же пользователя.

## Изменение границы доверия

Публичный статусный credential сохранён для обновления, но больше не даёт права
выполнения. Неизменяемое предложение хранится в службе, а повышенный помощник
читает его через отдельный TLS-канал и показывает точное действие перед commit.
Windows использует RunAs/UAC и elevated MessageBox; macOS — системный запрос
администратора и подтверждение AppleScript. Помощник принимает только случайный
ID, читает credentials по фиксированному системному пути и не выводит результат
регистрации или ключи аккаунта. Отмена и повтор не выполняют команду.

Публичный и приватный каналы закрепляют сертификат службы; её перезапуск меняет
административный token и сертификат. Сертификат для UI открыт на чтение, private
credentials закрыты правами службы/администратора. Интерфейс поставляется внутри
Electron-пакета, поэтому захват старого loopback-порта не подменяет его код.
После изменения питания UI повторяет только чтение, а не исходную команду.

Обычные локальные процессы могут читать диагностическое состояние и мешать
доступности, но не должны менять политику. Root/Administrator, служебная учётная
запись и системные разрешения, уже выданные пользователем, не изолированы этой
защитой. Подробности и ограничения: [security.md](security.md).

## Имя и обновление

Версия исходников — 0.3.0. Видимые имена desktop, Android, веб-интерфейсов,
уведомлений и установщиков — «Сеть». Добавлены PNG, ICO, ICNS, tray и Android
mipmap-иконки. Сохранены appId, executable/service ID, Android package, пути
данных, MSI UpgradeCode и требования к существующей Android-подписи. Старый
macOS bundle удаляется только после появления нового с тем же bundle ID;
занятый чужим приложением путь останавливает установку до изменения службы.
Установщики и подписанные APK/DMG/MSI этим коммитом не публикуются.

Полный portable/UI набор не считается пройденным из-за указанных ограничений.
Linux-тесты и кросс-сборка не подтверждают работу UAC, AppleScript, Windows DACL,
PF/WFP, подписи установщика или вид иконок в оболочке целевой ОС. Нужны
[нативные сценарии](acceptance.md), включая смену режимов, отказ и перезапуск
туннеля, cancel системного окна, чистую установку и обновление прежней версии.
Native CI fixture использует существующие административные права runner и
не является интерактивным тестом системных окон.
