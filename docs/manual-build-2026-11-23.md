# Сеть 0.3.0 — проверка PR и установщиков

23 ноября 2026. Проверены и объединены все открытые PR: [#39](https://github.com/jEUGENEdev/vpn/pull/39) и [#40](https://github.com/jEUGENEdev/vpn/pull/40). После объединения открытых PR нет.

Исходники выпуска: `5f37180b5d19e531fe3ae3198859f58c94b46f5e`. Коммит объединения — `df12705408e30f6cbdd50912530e8d464df9c850`; следующий коммит исправляет только путь входного macOS bundle при упаковке. Исходники приложений, Go-модули и lock-файлы между ними идентичны. В локальном checkout сверены Git blob SHA исходников с удалённым деревом; нормализованы только CRLF при сверке Windows-скриптов. Файлы документации, не влияющие на сборку, не использовались как исходники.

## Изменения

- #39: разрешения VPN для приложений, режим всего трафика, подтверждение привилегированных desktop-команд через ОС, название и иконки «Сеть», версия 0.3.0.
- #40: повтор DNS-запроса по TCP, обновление параметров REALITY, ограничения специальных IPv6-назначений на сервере.
- При реальной упаковке выявлено, что `executableName=LineVPN` заставляет Electron Builder создавать `LineVPN.app`. Исправлен `scripts/package-macos.sh`: исходный bundle копируется в `/Applications/Сеть.app`. Идентификатор `dev.linevpn.desktop` и исполняемый файл `LineVPN` сохранены для обновлений.

## Готовые файлы

Один полный комплект: APK Android 10+ (ARM64 и x86_64), MSI Windows x64, DMG macOS Apple Silicon и Intel. Дополнительно собраны сервер и генератор профилей Linux amd64. Все имена содержат `0.3.0` и/или `5f37180`; точные размеры и SHA-256 находятся в `manifest.json` и `SHA256SUMS`.

Android: `dev.linevpn.app`, versionName `0.3.0`, versionCode `3000`, minSdk 29, targetSdk 35, release без `debuggable`. Использован прежний постоянный ключ от 19.11.2026, SHA-256 сертификата `a5ed967ba9dd5cc7626793c6b8eae8ab7d8a904e855355b71d6ba9b17e84b8a5`. Идентичность подписи совместима с APK 0.2.1 от 19.11.2026; установка обновления на устройстве не выполнялась. Переход со старой 0.2.0, подписанной другим ключом, по-прежнему требует миграции по `docs/android-signing.md`.

Windows: постоянный UpgradeCode сохранён; ProductCode соответствует 0.3.0. Проверены последовательность транзакционного обновления, ремонт той же версии, запуск восстановления сети только при явном удалении и сохранение идентичности службы. В ручной сборке wixl отдельно восстановлены кириллица и code page 1251; проверены название продукта, службы, меню, ярлыка, ресурсов EXE и новая иконка.

macOS: каждый DMG содержит `Установить-Сеть.pkg`, команду установки и удаления. PKG устанавливает приложение и службу вместе, сохраняет идентификаторы `dev.linevpn.desktop` и `dev.linevpn.service`. Образы сформированы как HFSX/UDZO для корректных кириллических имён; временный инструмент mkdmg включает поддерживаемый библиотекой CaseSensitive, патч приложен к рецепту.

## Ограничения выпуска

Preview: установка, обновление и сетевое поведение на физических Android/Windows/macOS не проверены. Windows без Authenticode; macOS приложение и агент имеют ad-hoc подписи, PKG не подписан Apple и нотарификации нет. Проверка хешей на Linux не заменяет Apple codesign/Gatekeeper. VPS не обновлён. Для новых серверных функций требуется соответствующая версия сервера.

Комплект подготовлен для [релиза v0.3.0-preview.20261123](https://github.com/jEUGENEdev/vpn/releases/tag/v0.3.0-preview.20261123). SHA-256 всех шести бинарников на стороне GitHub совпали с локальными файлами. GitHub удаляет кириллицу из имён вложений, поэтому установщики в Assets имеют префикс `Set-`; внутри пакетов название остаётся «Сеть». Старые опубликованные релизы сохранены. Приватный Android-ключ и его пароли в комплект не включены.
