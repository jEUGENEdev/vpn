# Сверка PR #16, #17 и уже слитого #18

17 ноября 2026 года. База main: `cf3ee7c4513abd5d76274745ba0e4459e61cfd2e`.
Проверены точные деревья PR #16 (`69d306941aa92e5bcc6899ec8231f821cdffe2d7`) и #17 (`c58609e77a43b8e1a731e1b31ec53876e92a4569`). Локальные исходники сверены по Git blob SHA.

## Результат

- Сохранены изменения #18: одновременные устройства, раздельные UDP-назначения, частичный резерв в UI/Android, ограниченный кэш и отзыв действующих потоков при сужении доступа.
- Из #16 перенесены сохранение неизменившихся соединений при синхронизации профиля, защита от устаревшего результата dial и отсутствие ложного прямого резерва у одностороннего UDP/при простое.
- Из #17 перенесены независимый резерв для адреса, приложения, TCP/UDP и порта; наблюдение повторных безответных UDP-отправок в одном потоке; расширение сгруппированных доменных/IP-правил без перезапуска Xray.
- При объединении сохранены проверки конфигурации и закрытие старого транспорта при ошибке Apply из #18. Все новые правила по-прежнему должны разрешать трафик одной существующей учётной записи. Сужение/отзыв требует перезапуска, который может затронуть другие устройства.
- Добавлены проверки повторного входа и отзыва одного из двух устройств с одинаковыми именами; сохранены проверки обычных и app-ключей обоих устройств.

## Проверено

Полный `go test -race -tags with_gvisor ./...`, `go vet -tags with_gvisor ./...`, DOM-тесты и проверка recovery packaging прошли. Реальные локальные Xray/VLESS/XHTTP/REALITY проверяют одновременный TCP/UDP двух клиентов, добавление устройства и расширение правил; sing-tun NAT проверяет несколько адресатов одного сокета и IPv6. Синхронизация профиля, односторонний UDP, повторные безответные отправки, поздний ответ и изоляция резерва покрыты отдельными регрессиями.

Нативная установка/работа на устройствах пользователя и реальный VPS ещё не проверены. Для применения нужны новые сервер и клиенты. База, профиль, сертификаты и существующие ключи совместимы. Состояние опубликованного комплекта определяется `installers/current/manifest.json`.
