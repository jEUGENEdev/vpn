# Установка, обновление и удаление

Актуальные файлы всех платформ находятся в [едином каталоге](../installers/current/). Старые выпуски — только в [GitHub Releases](https://github.com/jEUGENEdev/vpn/releases). Версия и исходный коммит каждого комплекта записаны в `manifest.json`, контрольные суммы — в `SHA256SUMS`.

| Платформа | Установка и обновление | Удаление |
|---|---|---|
| macOS Intel / Apple Silicon | Один universal DMG → «Установщик Сеть» → «Установить» / «Обновить». Повторный запуск восстанавливает эту же версию | Тот же установщик → «Удалить». Встроенный новый recovery работает и при сломанной прежней установке |
| Windows x64 | Запустить MSI поверх прежнего приложения. Major upgrade сохраняет данные; повторный `/i` той же версии выполняет repair | Системный список установленных приложений |
| Android 10+ | Установить APK поверх приложения с тем же постоянным ключом. Package ID `dev.linevpn.app` сохраняется | Системное удаление приложения очищает его приватные локальные данные |

При обновлении сохраняются профиль, вход, идентификатор устройства, адресные правила, решения приложений и режим VPN. Каталоги данных не включены в заменяемый payload: `%ProgramData%\LineVPN`, `/var/lib/linevpn` и Android `filesDir`. Настройки desktop остаются в прежнем каталоге Electron `LineVPN` независимо от отображаемого названия «Сеть».

Обновление не вызывает `recover-network` и не снимает защиту. Установщик останавливает прежние процессы до замены файлов. Только явное выключение, удаление или административное восстановление разрешает прямое подключение. Старый установленный пакет может исполнять свои прежние lifecycle-скрипты: отсутствие сетевых утечек при переходе со старых версий требует проверки на целевой ОС.

На Windows сохранён UpgradeCode `{0ACF9EA2-83F8-4EE0-8877-E3BAE8A42E91}`; ProductCode определяется версией. Более старый MSI блокируется, удаление предыдущих файлов входит в транзакцию. Код 3010 требует перезагрузки. На macOS сохраняются идентификаторы приложения и receipt; более старая версия и другой системный том отклоняются. [Подробности macOS](macos-installation.md).

В 0.3.2 Windows заменяет файлы приложения и обновляет значки также при переходе на новую версию, даже если старый EXE сохранил более высокий номер версии Electron. Проверка готового MSI сверяет `File.Version` с ресурсами EXE/DLL; опубликованный вручную MSI 0.3.1 пропускал эти значения. Ярлык «Сеть» размещается непосредственно в общем меню «Пуск» с отдельной идентичностью компонента; прежние зарегистрированные ярлыки удаляет старый MSI в транзакции обновления. Пользовательские закрепления и ярлыки других Electron-приложений не удаляются. Эти изменения не требуют обновления сервера.

Android 0.3.2 имеет versionCode **3002**. Ключ не меняется относительно 0.2.1 от 19.11.2026, 0.3.0 и 0.3.1; совместимость обновления проверена по опубликованному APK 0.3.1. Для старой 0.2.0 с другим сертификатом сохраняется отдельный [порядок миграции](android-signing.md); новый ключ при обычной сборке не создаётся.

Версия определяется `apps/desktop/package.json` и должна совпадать с lockfile. Проверки исходников допускают совпадение с опубликованной версией. Публикация нового комплекта требует увеличения версии и проверяет сертификат реального APK; неполный комплект не заменяет текущий.

Перед выпуском на одноразовых целевых ОС требуется проверить прежний опубликованный пакет → новый, повторную установку, удаление, сохранение настроек, отсутствие второго экземпляра службы и поведение IPv4/IPv6 при сбоях. Переносимые тесты и проверка содержимого архивов не заменяют эти проверки. Выполненные проверки и недоступные проверки перечислены в отчёте конкретного выпуска.

История: [объединение PR 20–24](pr-20-24-integration.md), [сборка 0.3.0](manual-build-2026-11-23.md).
