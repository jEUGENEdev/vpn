# Повторная установка и обновление

Изменения PR #23 и #24 согласованы вместе с защитой при сбое из PR #21. Актуальная инструкция: [обновление клиента поверх установленного](installer-upgrade.md). Проверка объединения: [PR #20–24](pr-20-24-integration.md).

Сохранены проверки из обоих вариантов: остановка старых процессов до замены, отказ от второго экземпляра службы, сохранение profile/applications/ui-token и режима off, транзакционный порядок MSI, повторная установка, проверка подписи реального APK перед публикацией.

Итоговая версия — `0.2.1`, Android versionCode — `2001`. Для macOS используется единый `Install-LineVPN.pkg`; MSI получает стабильный ProductCode на версию и repair при повторном запуске. Версия берётся из `apps/desktop/package.json`, ожидаемый сертификат Android — из предыдущего manifest. Отдельный androidVersionCode в package.json и второй проверяющий скрипт удалены при объединении, чтобы упаковщики не расходились.

PR собирают только тестовые APK с временной debug-подписью; эти артефакты не публикуются как обновления. Выпуск main требует исходный ключ через `ANDROID_KEYSTORE_BASE64` и соответствующие `ANDROID_STORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`. Ключи и секреты этой проверкой не создавались и не изменялись.

Новые update hooks не вызывают recovery. Старый установленный MSI или macOS supervisor может выполнить собственный recovery при остановке: его поведение нельзя изменить задним числом. Отсутствие прямого трафика при обновлении старых клиентов требует нативной проверки. Удаление и административный recovery восстанавливают сеть явно.
