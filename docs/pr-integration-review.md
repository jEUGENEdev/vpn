## Исправления при объединении

- Проверка личного ключа/профиля и выбор или создание устройства выполняются в одной транзакции. Предварительный показ списка устройств не разрешает последующий вход с отозванным ключом или профилем; код привязки расходуется только после завершения выбора.
- После замены ключа повторный вход создаёт новую запись вместо восстановления отозванных учётных данных. Устаревший сеанс устройства не может заменить ключ аккаунта после повторной авторизации того же устройства.
- Форма сохраняет введённый ключ/код только на время второго шага выбора устройства и очищает его после завершения. Автоматическое имя, поиск и новые формы объединены с доступной адаптивной разметкой.
- После удаления устройства переключатель VPN не скрывает необходимость входа. Сохранённый аккаунт остаётся привязан к прежнему серверу и сертификату даже после очистки токена устройства.
- Общие UI-сценарии обновлены под вход по ключам, выбор устройств, поиск и вёрстку. Добавлены регрессионные Go- и DOM-проверки взаимодействия этих функций.

## Неподтверждённые проверки

У исходных PR GitHub Actions завершились до исполнения шагов: `runner_id=0`, список steps пуст, сборки пропущены. Точная причина старта runner из доступного ответа API не установлена. Это не успешный CI.

Playwright здесь завершается до открытия страницы: Chromium не может создать системный socket (`Operation not permitted`). Поэтому визуальная геометрия, 90 сочетаний ширины/темы/раздела и нативные диалоги не считаются проверенными. DOM-тесты не заменяют браузерный прогон.

Реальный VPS, Android, Windows и macOS/Gatekeeper не проверялись. Новые APK/MSI/DMG не публиковались; содержимое `installers/current/manifest.json` остаётся источником версии установщиков. Подписанный macOS release требует сертификатов и нотарификации владельца.

Перед обновлением сервера учтите миграцию: пользовательские пароли заменены ключами. Старым аккаунтам администратор выдаёт новые ключи; для нового входа нужны обновлённые клиенты и профиль с `access`. Подробности — [deployment.md](deployment.md#перевыпуск-профиля-и-переход-на-ключи) и [client.md](client.md).
