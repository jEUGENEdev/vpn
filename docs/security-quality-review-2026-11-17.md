# Проверка изменений безопасности и качества — 17 ноября 2026

Исходный `main`: `cdda72dee008a8fe7d9860237da3ca88febe878f`.
Область работы: инструкции агентам, воспроизводимые проверки, CI и находки этих
проверок. Это не полный аудит кода, истории Git, установленных клиентов или VPS.

## Исправлено

- `github.com/klauspost/compress` обновлён с 1.20.1 до 1.20.2:
  [GO-2026-6865](https://osv.dev/vulnerability/GO-2026-6865), panic при разборе
  некорректных данных. Уязвимая версия была в графе сборки; достижимость конкретного
  дефекта из внешнего VPN-трафика отдельно не доказана.
- После отмены подтверждения клиент возвращает клавиатурный фокус на исходную
  кнопку, даже если Chromium оставил его внутри уже закрытого диалога. До правки
  браузерная проверка возврата фокуса завершалась таймаутом; после правки проходит.
- Исправлены устаревший селектор вложенного `summary`, ожидание асинхронного
  очищения одноразового ключа и отсутствие повторного входа между сценариями
  админки. Проверки очистки ключа, фокуса и авторизации сохранены.

## Открытые находки зависимостей

OSV использовал локальные публичные базы Go, npm и PyPI, скачанные 17 ноября 2026.
Состав зависимостей не отправлялся в сервис аудита. Проверены шесть manifest/lock
files, перечисленных в `scripts/check-security.sh`.

| Зависимость в desktop lockfile | Advisory | Что ещё требуется |
| --- | --- | --- |
| `minimatch` 10.2.6 и 9.0.9 | [GHSA-g3hv-75wg-m249](https://github.com/advisories/GHSA-g3hv-75wg-m249), DoS через globparts amplification | Исправление начинается с 11.0.1; текущие родители запрашивают major 9/10. Нужны совместимое обновление сборщика или проверенный override и сборки Windows/macOS |
| `picomatch` 4.0.7 | [GHSA-fc5q-39xc-vjpf](https://github.com/advisories/GHSA-fc5q-39xc-vjpf), ReDoS в extglob | На момент проверки в npm не опубликована исправленная версия; требуется исправление upstream либо отдельно проверенная замена/patch |

Обе зависимости используются цепочкой сборки Electron. В текущем `package.json`
они относятся к devDependencies; конфигурация упаковки перечисляет `main.cjs` и
`preload.cjs`. Находки по версиям не доказывают эксплуатацию из трафика установленного
клиента. Однако исключения не добавлены: security gate остаётся красным и
блокирует сборку/деплой до устранения или отдельного обоснованного решения.

OSV JSON также содержит GO-2026-5932 для устаревшего пакета `x/crypto/openpgp`.
Сканер помечает его как неиспользуемый; `go list -deps -tags with_gvisor ./...`
в Linux не содержит `openpgp`. Это не подтверждение покрытия других ОС.

Тест `test_generated_admin_password_survives_redeploy` не выполнен из-за
ограничения среды: Ansible не может поднять Local RPC server, создание AF_UNIX
сокета возвращает `Operation not permitted`. Проверка не пропущена и её
утверждения не ослаблены; повторить на обычном Linux runner с указанными tools.

Нативные проверки Windows/macOS/Android, выпуск установщиков, изменение branch
protection и деплой VPS в эту работу не входили. Локальный результат не является
статусом GitHub Actions; фактический статус удалённых jobs нужно смотреть в PR.
Перед merge необходимы устранение блокирующих advisory и полный успешный CI.
