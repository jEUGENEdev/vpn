# Установка «Сеть» на macOS

Для Intel и Apple Silicon используется один universal DMG. Новая схема 0.4:
**полное удаление → чистая установка**, без обновления поверх и восстановления.

1. Сохраните профиль сервера и ключ доступа. Локальные настройки и вход будут удалены.
2. Откройте новый DMG → **«Установщик Сеть.app» → «Удалить»**, подтвердите удаление и права администратора.
3. Снова откройте установщик → **«Установить»**. Он автоматически выберет архитектуру, включая запуск через Rosetta.
4. После проверки службы нажмите **«Открыть Сеть»**, добавьте профиль и войдите.

Новый установщик удаляет старые `LineVPN.app` и `Сеть.app` с идентификатором
`dev.linevpn.desktop`, LaunchDaemon, служебные файлы и `/var/lib/linevpn`.
Очищается каталог интерфейса `~/Library/Application Support/LineVPN`, кэш и
настройки приложения. Чужие Electron-приложения не затрагиваются. Учётная запись
`_linevpn` удаляется только после проверки её служебных UID/GID, shell и home.

Удаление использует код из нового DMG и работает при отсутствующем старом агенте.
Пока worker или интерфейс не остановлены, очистка сети запрещена. При ошибке
сетевой очистки файлы и данные остаются для повторного удаления. Простое
перемещение приложения в корзину не заменяет этот сценарий.

Установка проверяет HTTPS API, TUN и PF до сообщения об успехе. Если она прервалась,
сначала выберите **«Удалить»**, затем **«Установить»**. Журнал операции указан в
сообщении установщика: `/var/log/linevpn-installer.*`. Служба пишет ошибки в
`/var/log/linevpn-error.log`, Apple Installer — в `/var/log/install.log`.
Если процесс нельзя завершить, перезагрузите Mac и повторите удаление.

Preview подписан ad-hoc и не нотарифицирован Apple. Проверка:
`codesign --verify --deep --strict /Applications/Сеть.app`.
Для проверенного файла Gatekeeper может предложить **Системные настройки →
Конфиденциальность и безопасность → Всё равно открыть**. Установщик не отключает
Gatekeeper и не удаляет quarantine. Для доверенного выпуска нужны Developer ID
сертификаты владельца и нотарификация.

Сборка: `scripts/package-macos.sh`. В одном DMG находятся один launcher и два
внутренних payload. `scripts/test-macos-package.sh` проверяет обе архитектуры,
подписи и содержимое пакетов. `scripts/test-macos.sh` проверяет настоящий цикл
установки/удаления/новой установки на одноразовом Mac, включая отказ повторной
установки, отсутствующий EXE, DNS, остановку, crash и запуск Electron обычным
пользователем. Linux fixtures не подтверждают поведение launchd/PF.
