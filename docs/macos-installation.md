# Установка «Сеть» на macOS

Начиная с 0.3.1 для Intel и Apple Silicon используется **один `macos-universal.dmg`**. [Актуальный комплект](../installers/current/).

1. Откройте DMG и **«Установщик Сеть.app»**.
2. Выберите **«Установить»** или **«Обновить»**. Установщик сам выбирает архитектуру, включая запуск через Rosetta.
3. Подтвердите запрос прав администратора macOS. После завершения нажмите **«Открыть Сеть»**.

Повторный запуск устанавливает текущую версию заново с сохранением данных. Старую версию заранее удалять не нужно. Установщик обновляет `/Applications/Сеть.app` и фоновую службу вместе; идентификаторы `dev.linevpn.desktop` и `dev.linevpn.service` сохранены. Старый `LineVPN.app` удаляется только после появления нового приложения с тем же идентификатором. Чужое приложение по этому пути не заменяется. Установка более старой версии и установка на другой системный том отклоняются до остановки процессов.

## Удаление

Откройте **тот же установщик** и выберите **«Удалить»**. После отдельного подтверждения он остановит интерфейс и службу, восстановит прямое подключение, удалит только файлы «Сеть» и её запись установки. Профиль, правила и идентичность устройства в `/var/lib/linevpn` сохраняются для повторной установки.

Используется механизм удаления из нового DMG, а не старый `uninstall.sh`. Поэтому удаление доступно после неполной установки, отсутствия старого агента или ошибки «невозможно остановить LineVPN». Установщик ждёт завершения launchd и worker; если мягкая остановка не помогает, завершает только процессы по точным путям «Сеть». Пока служба или worker остаются активны, восстановление сети и удаление файлов запрещены. Ошибка восстановления также сохраняет файлы для повторной попытки.

Обновление не вызывает восстановление сети и не сбрасывает действующие правила PF. Удаление и явное административное восстановление — отдельные действия. [Границы защиты](security.md).

## Если операция завершилась ошибкой

- В установщике 0.3.1 ошибка `Cannot compare installed Сеть version` могла возникать и на чистом Mac: при отсутствии `LineVPN.app` или `Сеть.app` диагностический текст `PlistBuddy` ошибочно считался версией. Исправление 0.3.2 проверяет наличие приложения и успешность чтения метаданных. Для этой ошибки перезагрузка, удаление профиля и очистка правил не нужны; используйте исправленный установщик. Повреждённые метаданные существующего приложения и понижение версии по-прежнему отклоняются до остановки службы.
- Новый установщик показывает ошибку и путь к журналу `/var/log/linevpn-installer.*`. Для установки дополнительные сведения находятся в `/var/log/install.log`, для работы службы — в `/var/log/linevpn-error.log`.
- Если старый процесс действительно не завершается, перезагрузите Mac и повторите нужное действие в новом установщике.
- После прерванной установки повторно выберите «Обновить». Полный транзакционный откат Apple Installer не гарантируется; профиль и правила не входят в заменяемый payload.
- Сверьте размер и SHA-256 DMG с manifest, затем проверьте `hdiutil verify /путь/к/Set.dmg`. Не снимайте защиту с повреждённого файла.
- Проверка целостности установленного приложения: `codesign --verify --deep --strict --verbose=2 /Applications/Сеть.app`.

Preview использует ad-hoc подпись и не нотарифицирован Apple. Gatekeeper может запросить разрешение: для проверенного вами файла используйте **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**, если этот вариант доступен. Установщик не отключает Gatekeeper и не удаляет quarantine. Нужны реальные Developer ID сертификаты владельца для доверенного подписанного выпуска.

## Сборка и проверка

На macOS: `scripts/package-macos.sh`. Скрипт собирает два внутренних PKG и один universal launcher, помещает их в один установщик и один DMG. Пользователь видит только установщик; отдельные команды установки/удаления в образ не добавляются.

`scripts/test-macos-package.sh` проверяет обе архитектуры, подписи, версии, вложенные recovery-бинарники и компиляцию AppleScript. `scripts/test-macos.sh` на одноразовом CI Mac проверяет установку через новый управляющий сценарий, повторную установку, сохранение данных, сетевую защиту и удаление. Наличие этих тестов не означает, что конкретный опубликованный файл прошёл их на Mac: результаты и ограничения указаны в отчёте выпуска.

Для подписанного выпуска задаются `LINEVPN_MACOS_SIGNING=release`, `LINEVPN_MACOS_APP_IDENTITY`, `LINEVPN_MACOS_INSTALLER_IDENTITY` и `LINEVPN_MACOS_NOTARY_PROFILE`. Скрипты подписывают и нотарифицируют приложения, оба PKG, установщик и DMG; ошибки подписи останавливают сборку.
